# Сборка и проверка установщика

## Установочные файлы

Автономный установщик — `dist/lucx-post-configure.sh`. Его контрольная сумма находится в `dist/SHA256SUMS`. Используйте оба файла из одного коммита репозитория.

Готовые команды скачивания с GitHub и через gh-proxy приведены в [быстром старте](QUICKSTART_RU.md). Они проверяют SHA-256 перед запуском установки. Для ручной передачи файлов смотрите [установку из файла](INSTALL_FROM_FILE_RU.md).

Самостоятельный загрузчик `install.sh` по умолчанию обращается к репозиторию `x-tuna`. Для установки используйте быстрый старт или автономный файл из `dist/`.

## Проверка файла на сервере

В каталоге с установщиком и файлом контрольных сумм выполните:

```bash
sha256sum -c SHA256SUMS
```

Продолжайте установку только при результате `OK`. При несовпадении суммы повторно скачайте оба файла из одного коммита.

## Сборка из исходников

Для сборки требуется Python 3.11+:

```bash
python3 tools/build_installer.py
```

Сборка создаёт установщик и `SHA256SUMS` в `dist/`. Повторная сборка неизменённых исходников должна давать тот же SHA-256. Файлы в `dist/` вручную не редактируются.

## Проверки

Обязательные локальные проверки: compileall, unittest, проверка документации и секретов, shell-синтаксис и две детерминированные сборки. Пропущенные на Windows проверки не подтверждают работу соответствующих функций на Linux.

После установки проверьте состояние служб, открытие сайтов и подключение каждого используемого VPN-профиля. Локальные тесты не заменяют эту проверку на сервере. Подробнее — [порядок тестирования](TESTING_RU.md) и [результат внешнего сканирования](BYEBYEVPN_RU.md).
