# DNS, BBR и Cloudflare origin

## Системный DNS

Раздел **3 → 1** предлагает резолверы и измеряет задержку. Выбор меняет системный DNS в рамках соответствующей операции; он не создаёт DNS-записи вашего домена. После смены проверяйте разрешение доменов панели, подписки и протоколов.

`x-tuna --dns-diagnostic` выполняет расширенную диагностику DNS и изоляции служб. Команда обращается к сети. Ошибка одного внешнего резолвера не обязательно означает отказ VPN; сравните результат с доступностью ваших доменов.

## TCP BBR и FQ

Раздел **3 → 2** показывает алгоритм TCP congestion control, очередь и буферы. BBR управляет скоростью отправки TCP, FQ распределяет очередь пакетов. Поддержка зависит от ядра.

```bash
x-tuna --network-tuning-status
```

**CLI-команды `x-tuna --network-tuning-apply` и `x-tuna --network-tuning-revert` изменяют систему сразу, без вопроса подтверждения.** Для пошагового выбора используйте меню 3 → 2. Просмотр не применяет настройку. Apply записывает `/etc/sysctl.d/60-lucx-bbr.conf` и применяет sysctl. Revert удаляет этот файл и запускает `sysctl --system`. Значения берутся из оставшихся конфигураций; параметры, для которых там нет записи, могут остаться текущими. Это **не восстановление прежних значений и не гарантия возврата defaults**. Механизм отличается от общего Engine backup/rollback: не обещайте, что откат доменов автоматически вернёт прежний TCP tuning.

Изменения имеют системный охват. Сравнивайте результат на своих соединениях; скорость зависит также от канала, загрузки и клиента. BBR не исправляет неверный сертификат, DNS или путь WebSocket.

## Ограничение Cloudflare origin

Раздел **3 → 3** включает или отключает ограничение прямого доступа к панели и подписке в обход прокси Cloudflare. Перед включением убедитесь, что соответствующие DNS-записи проксируются, выбран совместимый HTTPS-порт и сертификат подходит.

Прямой запрос к origin после включения может быть намеренно заблокирован. Это не поломка, если доступ через Cloudflare работает. При выключенной проксируемости DNS адрес origin остаётся прямым: ограничение нужно согласовать с этим режимом.

Обычный Cloudflare HTTP proxy не является универсальной публикацией всех TCP/UDP-протоколов VPN. Применяйте настройки только к указанным в плане точкам входа. SSH-доступ и отдельные VPN-порты проверяются отдельно.
