# Быстрый старт

## Перед установкой

В LucX уже должны быть созданы администратор, протоколы и клиенты. Сначала проверьте хотя бы одно подключение клиентским приложением: это позволит отличить исходную проблему VPN от настройки внешней обвязки.

Подготовьте домен, DNS и сертификат. Во всех примерах `example.test` означает ваш собственный домен; этот пример не нужно буквально добавлять в DNS. `panel.example.test` — адрес панели, `sub.example.test` — адрес подписки. Сертификат `*.example.test` покрывает один уровень поддоменов, но для самого `example.test` нужно отдельное покрытие в сертификате.

Сохраните снимок VPS у провайдера. Он полезен для возврата всей системы; резервная копия x-tuna предназначена для управляемой конфигурации и не заменяет полный снимок сервера.

## Быстрый старт

Выполните **весь блок** в SSH-консоли сервера от **root**. Требуются Debian 12/13, Python 3.11+ и уже установленная LucX. Команда скачивает проверенную сборку, сверяет SHA-256 и устанавливает постоянные команды x-tuna. Флаг `--yes` заранее подтверждает именно установку команд; настройка доменов и VPN-маршрутов запускается отдельно через меню.

Если отсутствуют необходимые пакеты, сначала установите их:

```bash
apt-get update && apt-get install -y python3 curl ca-certificates
```

Прямое скачивание из этого репозитория GitHub:

```bash
bash -c '
set -euo pipefail
[ "$(id -u)" -eq 0 ] || { echo "Выполните команду от root (sudo -i)." >&2; exit 1; }
python3 -c "import sys; sys.exit(sys.version_info < (3, 11))" || { echo "Нужен Python 3.11 или новее." >&2; exit 1; }
command -v curl >/dev/null || { echo "Установите curl: apt-get update && apt-get install -y curl ca-certificates" >&2; exit 1; }
tmp=$(mktemp -d)
cleanup() { rm -f -- "$tmp/lucx-post-configure.sh"; rmdir -- "$tmp"; }
trap cleanup EXIT
curl --fail --location --proto "=https" --tlsv1.2 --retry 2 --connect-timeout 15 --max-time 180 "https://raw.githubusercontent.com/534188-create/x-tuna/main/dist/lucx-post-configure.sh" -o "$tmp/lucx-post-configure.sh"
printf "%s  %s\n" "0f8386ea45c0ea30feea0b051d3299283579332a9246b0b05d7c85fc16461322" "$tmp/lucx-post-configure.sh" | sha256sum -c -
sh "$tmp/lucx-post-configure.sh" --install-tui --yes
echo "Установка завершена. Откройте меню командой: x-tuna"
'
```

## Быстрый старт на VPS в России — через gh-proxy

Если прямое скачивание GitHub недоступно или медленно, используйте этот вариант. Условия те же, повторно запускать обычный вариант не нужно. Файл скачивается через [gh-proxy](https://gh-proxy.com/en), а ожидаемый SHA-256 закреплён в самой команде. Доступность стороннего сервиса зависит от сети VPS.

```bash
bash -c '
set -euo pipefail
[ "$(id -u)" -eq 0 ] || { echo "Выполните команду от root (sudo -i)." >&2; exit 1; }
python3 -c "import sys; sys.exit(sys.version_info < (3, 11))" || { echo "Нужен Python 3.11 или новее." >&2; exit 1; }
command -v curl >/dev/null || { echo "Установите curl: apt-get update && apt-get install -y curl ca-certificates" >&2; exit 1; }
tmp=$(mktemp -d)
cleanup() { rm -f -- "$tmp/lucx-post-configure.sh"; rmdir -- "$tmp"; }
trap cleanup EXIT
curl --fail --location --proto "=https" --tlsv1.2 --retry 2 --connect-timeout 15 --max-time 180 "https://gh-proxy.com/https://raw.githubusercontent.com/534188-create/x-tuna/main/dist/lucx-post-configure.sh" -o "$tmp/lucx-post-configure.sh"
printf "%s  %s\n" "0f8386ea45c0ea30feea0b051d3299283579332a9246b0b05d7c85fc16461322" "$tmp/lucx-post-configure.sh" | sha256sum -c -
sh "$tmp/lucx-post-configure.sh" --install-tui --yes
echo "Установка завершена. Откройте меню командой: x-tuna"
'
```

После успешной установки:

```bash
x-tuna
```

Для первичной настройки выберите **2. Настройка → 1. Первичная настройка**. Если скачивание, проверка SHA-256 или установка завершатся ошибкой, сообщение об успешной установке не появится. Обе команды используют один зафиксированный снимок приложения; при новой поставке ссылка и ожидаемый хеш обновляются вместе. Это установка x-tuna, а не установка панели LucX с нуля.

## Установить программу из локальных файлов

Перенесите из одной поставки `dist/lucx-post-configure.sh` и `dist/SHA256SUMS` в `/root/x-tuna-install/`. Инструкция с командами для Windows — [установка из файла](INSTALL_FROM_FILE_RU.md).

```bash
cd /root/x-tuna-install
sha256sum -c SHA256SUMS
sh ./lucx-post-configure.sh --audit
sh ./lucx-post-configure.sh --install-tui
x-tuna
```

Если хеш не совпал, заново получите согласованную пару файлов. Не исправляйте checksum вручную. Если аудит сообщает несовместимую ОС или схему панели, не переходите к применению.

## Первая настройка

1. Откройте **1. Статус и диагностика** и просмотрите обнаруженные настройки.
2. Вернитесь в главное меню и выберите **2. Настройка → 1. Первичная настройка**.
3. Укажите свои домены и требуемые публичные точки входа. Внутренний порт — порт уже работающего backend LucX; не подменяйте его публичным 443.
4. Выберите сертификат, DNS и нужные компоненты. Sidecar устанавливайте, если он нужен для ваших подписок.
5. Прочитайте итоговый план: адреса, файлы, службы, предупреждения и возможные изменения.
6. Снова запустите аудит, проверьте итоговый план и только после проверки подтвердите цифрой `1`. `2` или Enter отменяют изменение.

При ошибке запишите действие и сообщение. Не запускайте несколько мастеров одновременно. Возвращайтесь к проверке статуса и журналу последнего запуска.

## Проверить результат

Откройте в браузере корневой домен и домены протоколов, проверьте сертификат. Откройте панель по её пути и порту. Обновите подписку, затем подключите каждый профиль и проверьте загрузку страницы, передачу данных и переподключение.

```bash
lucx-post-configure --validate
lucx-post-configure --repair-check
```

Прочитайте [руководство пользователя](USER_GUIDE_RU.md) для последующих изменений и [решение проблем](TROUBLESHOOTING_RU.md), если что-то не работает.
