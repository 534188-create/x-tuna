# Установка из файла

## Установка одной командой

В [быстром старте](QUICKSTART_RU.md) приведены два готовых блока: прямое скачивание GitHub и скачивание через gh-proxy для VPS в России. Оба проверяют SHA-256 до запуска и выполняют `--install-tui --yes`. Если предпочтительна ручная передача, следуйте инструкции ниже.

## Какие файлы нужны

Из одного снимка репозитория возьмите `dist/lucx-post-configure.sh` и `dist/SHA256SUMS`. Первый файл содержит программу; второй — ожидаемый SHA-256. Не смешивайте файл новой версии с checksum старой.

Для приватного репозитория скачайте файлы после входа на GitHub либо через настроенный GitHub CLI. Не помещайте токен GitHub в команду, которую сохраняет история shell. Публичная ссылка не предоставляет доступ к приватному репозиторию.

## Передача с Windows

Откройте обычный PowerShell. Укажите адрес вашего VPS и папку, куда вы скачали оба файла:

```powershell
$server = Read-Host 'Адрес вашего VPS'
$downloadDir = Read-Host 'Папка с lucx-post-configure.sh и SHA256SUMS'
ssh "root@$server" 'mkdir -p /root/x-tuna-install && chmod 700 /root/x-tuna-install'
scp (Join-Path $downloadDir 'lucx-post-configure.sh') (Join-Path $downloadDir 'SHA256SUMS') "root@${server}:/root/x-tuna-install/"
ssh "root@$server"
```

При нестандартном SSH-порте используйте `ssh -p ПОРТ` и `scp -P ПОРТ`. Пароль вводится в интерактивном запросе. Новый или изменившийся SSH-ключ сверяйте с консолью провайдера.

## Установка на Debian

```bash
cd /root/x-tuna-install
sha256sum -c SHA256SUMS
sh ./lucx-post-configure.sh --audit
sh ./lucx-post-configure.sh --install-tui
x-tuna
```

Команды рассчитаны на root и установленный Python 3.11+. `sh` позволяет запускать скачанный файл без отдельного `chmod +x`. Проверка суммы должна закончиться `OK`.

`--install-tui` устанавливает постоянные команды и сопутствующие файлы обслуживания. Эта операция не равна первичной настройке доменов: её запускают отдельно из меню **2 → 1**. Проверяйте показываемый программой план и подтверждение.

## Обновить только x-tuna

Получите новую согласованную пару файлов, проверьте SHA-256 и снова выполните `--install-tui`. Команда **4 → 1. Обновление LucX** обновляет панель, а не выбирает новую версию x-tuna из этого репозитория.

## Запуск без постоянной установки

```bash
sh ./lucx-post-configure.sh --help
sh ./lucx-post-configure.sh --audit
```

Для первичного знакомства достаточно справки и аудита. Запуск без параметров открывает меню и сам по себе не означает согласия на все изменяющие операции.

## Особенность сохранённых bootstrap-файлов

`install.sh` и `install-no-github.sh` перенесены без изменения логики. Для установки используйте автономный файл `dist/lucx-post-configure.sh`; именно он является поставкой x-tuna. Наличие старого URL в исходнике не означает, что новый релиз уже опубликован по этому URL.
