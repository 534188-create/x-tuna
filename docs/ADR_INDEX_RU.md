# Реестр архитектурных решений

ADR фиксируют решения, которые нельзя выводить только из текущего кода. Каждое
решение должно содержать статус, контекст, варианты, выбранный вариант и
последствия.

## Реестр

- `ADR-0001`: LucX устанавливается вручную.
- `ADR-0002`: исходный Naive Caddyfile неизменяем.
- `ADR-0003`: обновление запускается отдельным systemd worker.
- `ADR-0004`: sidecar является опциональным.
- `ADR-0005`: inbound и SNI обнаруживаются динамически.
- `ADR-0006`: VPN имеет приоритет над заглушкой.
- `ADR-0007`: qWDTT не публикуется через подписки.
- `ADR-0008`: настройки протокола могут изменяться LucX.
- `ADR-0009`: Cloudflare применяется только к подтверждённым доменам панели и подписки.

Изменение решения требует review, обновления тестов, контекста разработки и
документа безопасности.
