# Источники загрузки

Для установки используйте автономный dist/lucx-post-configure.sh и SHA256SUMS из одного снимка репозитория. [Пошаговая инструкция](INSTALL_FROM_FILE_RU.md).

## Быстрый старт через gh-proxy

Готовая команда находится в [быстром старте](QUICKSTART_RU.md). Используется адрес вида `https://gh-proxy.com/https://raw.githubusercontent.com/…`; `/en` — страница сервиса, а не добавляемый в путь файла сегмент. Команда закрепляет конкретный коммит x-tuna и SHA-256 установщика. Проверяемый хеш находится в инструкции, а не скачивается через то же зеркало.

При недоступности proxy используйте прямую команду либо перенос файла. Не отключайте TLS-проверку curl и не пропускайте проверку суммы. Это не канал автоматической публикации новых сборок x-tuna.

## Загрузчик install.sh

В локальной копии репозитория `install.sh` запускает файл из `dist/`. При отдельном скачивании загрузчик получает установщик и SHA256SUMS с GitHub и проверяет контрольную сумму перед запуском. Для регистрации команды `x-tuna` используйте готовый блок из [быстрого старта](QUICKSTART_RU.md).

## Обновление LucX

Обновление панели имеет свои источники auto, SourceCraft, GitHub и custom. Доступны поддержанные кодом прокси-шаблоны с {url} и пользовательский HTTPS-архив. Выбор источника влияет на доверие к получаемому коду. Прокси не заменяет проверку целостности и не предназначен для передачи секретов.

Подробнее: [обновление LucX](LUCX_UPDATE_RU.md). Не считайте стороннее зеркало автоматически доверенным только потому, что оно вернуло файл.
