# x-tuna

**x-tuna — постконфигуратор панели LucX для Debian 12/13.**

Настройка доменов, сайтов-заглушек, подписок, сертификатов, DNS и защиты сервера через русскоязычное меню. Для запуска введите `x-tuna` и выберите нужный пункт цифрой. Перед началом установите LucX и создайте подключения в панели.

## Быстрый старт

Выполните **весь блок** в SSH-консоли сервера от **root**. Требуются Debian 12/13, Python 3.11+ и уже установленная LucX. Команда скачивает проверенную сборку, сверяет SHA-256 и устанавливает постоянные команды x-tuna. Флаг `--yes` заранее подтверждает именно установку команд; настройка доменов и VPN-маршрутов запускается отдельно через меню.

Если отсутствуют необходимые пакеты, сначала установите их:

```bash
apt-get update && apt-get install -y python3 curl ca-certificates
```

Прямое скачивание из этого репозитория GitHub:

```bash
bash -c '
set -euo pipefail
[ "$(id -u)" -eq 0 ] || { echo "Выполните команду от root (sudo -i)." >&2; exit 1; }
python3 -c "import sys; sys.exit(sys.version_info < (3, 11))" || { echo "Нужен Python 3.11 или новее." >&2; exit 1; }
command -v curl >/dev/null || { echo "Установите curl: apt-get update && apt-get install -y curl ca-certificates" >&2; exit 1; }
tmp=$(mktemp -d)
cleanup() { rm -f -- "$tmp/lucx-post-configure.sh"; rmdir -- "$tmp"; }
trap cleanup EXIT
curl --fail --location --proto "=https" --tlsv1.2 --retry 2 --connect-timeout 15 --max-time 180 "https://raw.githubusercontent.com/534188-create/x-tuna/main/dist/lucx-post-configure.sh" -o "$tmp/lucx-post-configure.sh"
printf "%s  %s\n" "0f8386ea45c0ea30feea0b051d3299283579332a9246b0b05d7c85fc16461322" "$tmp/lucx-post-configure.sh" | sha256sum -c -
sh "$tmp/lucx-post-configure.sh" --install-tui --yes
echo "Установка завершена. Откройте меню командой: x-tuna"
'
```

## Быстрый старт на VPS в России — через gh-proxy

Если прямое скачивание GitHub недоступно или медленно, используйте этот вариант. Условия те же, повторно запускать обычный вариант не нужно. Файл скачивается через [gh-proxy](https://gh-proxy.com/en), а ожидаемый SHA-256 закреплён в самой команде. Доступность стороннего сервиса зависит от сети VPS.

```bash
bash -c '
set -euo pipefail
[ "$(id -u)" -eq 0 ] || { echo "Выполните команду от root (sudo -i)." >&2; exit 1; }
python3 -c "import sys; sys.exit(sys.version_info < (3, 11))" || { echo "Нужен Python 3.11 или новее." >&2; exit 1; }
command -v curl >/dev/null || { echo "Установите curl: apt-get update && apt-get install -y curl ca-certificates" >&2; exit 1; }
tmp=$(mktemp -d)
cleanup() { rm -f -- "$tmp/lucx-post-configure.sh"; rmdir -- "$tmp"; }
trap cleanup EXIT
curl --fail --location --proto "=https" --tlsv1.2 --retry 2 --connect-timeout 15 --max-time 180 "https://gh-proxy.com/https://raw.githubusercontent.com/534188-create/x-tuna/main/dist/lucx-post-configure.sh" -o "$tmp/lucx-post-configure.sh"
printf "%s  %s\n" "0f8386ea45c0ea30feea0b051d3299283579332a9246b0b05d7c85fc16461322" "$tmp/lucx-post-configure.sh" | sha256sum -c -
sh "$tmp/lucx-post-configure.sh" --install-tui --yes
echo "Установка завершена. Откройте меню командой: x-tuna"
'
```

После успешной установки:

```bash
x-tuna
```

Для первичной настройки выберите **2. Настройка → 1. Первичная настройка**. Если скачивание, проверка SHA-256 или установка завершатся ошибкой, сообщение об успешной установке не появится. Обе команды используют один зафиксированный снимок приложения; при новой поставке ссылка и ожидаемый хеш обновляются вместе. Это установка x-tuna, а не установка панели LucX с нуля.

## Что умеет программа

| Задача | Что получает пользователь |
|---|---|
| Первичная настройка | Мастер собирает параметры и показывает план внешней обвязки LucX |
| Домены и маршрутизация | Панель, подписка и протоколы получают согласованные публичные адреса |
| Сайты-заглушки | Обычный посетитель открывает сайт на настроенном домене; VPN получает свой маршрут |
| Подписки | Необязательный sidecar преобразует выдачу для совместимых клиентов |
| Сертификаты | Поиск подходящих сертификатов, управление продлением и выпуск через Cloudflare DNS-01 |
| DNS | Выбор системного DNS, измерение задержки и диагностика |
| Сеть | Просмотр и настройка TCP BBR, FQ и сетевых буферов |
| Cloudflare | Настройка ограничения прямого доступа к панели и подписке |
| Диагностика | Аудит, проверка сохранённой конфигурации, сайты и протокольные пробы |
| Обслуживание | Обновление LucX, ремонт обвязки после обновления, резервные копии и откат |
| TrustTunnel | Просмотр состояния LucX TrustTunnel и отдельного backend-кандидата |

Подробности и границы каждой возможности — в [карте функциональности](docs/FEATURES_RU.md). Поддержка названия протокола в панели не означает поддержку любой комбинации транспорта и TLS. Смотрите найденный план и сообщения программы.

## Что программа не делает за вас

- Не устанавливает LucX с нуля и не создаёт вместо вас VPN-клиентов.
- Не заменяет клиентское приложение на телефоне или компьютере.
- Не гарантирует, что сайт-заглушка исключает обнаружение VPN или блокировку оператором.
- Не подтверждает работоспособность всех клиентов одним зелёным результатом диагностики.

## Требования

- Debian 12 или 13, Python 3.11+, административный доступ.
- Установленная LucX, созданные inbound и клиенты, известные рабочие профили.
- Домены под вашим управлением, корректные DNS-записи и сертификаты.
- Для соответствующих компонентов нужны системные программы, например HAProxy, Nginx, nftables и средства выпуска сертификатов. Python runtime использует стандартную библиотеку.

Исходный Naive Caddyfile управляется панелью: вручную менять его ради x-tuna не нужно. Клиентов, ключи и внутренние порты не следует переносить или пересоздавать для установки обвязки.

## Установка из файла

Скачайте **оба файла** `dist/lucx-post-configure.sh` и `dist/SHA256SUMS` из одного снимка этого репозитория и загрузите их на сервер в `/root/x-tuna-install/`.

```bash
cd /root/x-tuna-install
sha256sum -c SHA256SUMS
sh ./lucx-post-configure.sh --audit
sh ./lucx-post-configure.sh --install-tui
x-tuna
```

Продолжайте после проверки хеша только при `OK`. Вопросы подтверждения: **1 — Да, 2 — Нет, Enter — Нет**. Установка команд и применение конфигурации — разные действия: после установки откройте **2 → 1** для первичного мастера.

Приведённые команды выполняются от root. Для обычного административного пользователя добавьте `sudo` к серверным операциям. Пошаговая передача с Windows — в [инструкции установки](docs/INSTALL_FROM_FILE_RU.md).

Для установки x-tuna используйте команды быстрого старта выше или `dist/lucx-post-configure.sh`. Отдельный загрузчик `install.sh` не используется для этого сценария.

## Главное меню

```text
1. Статус и диагностика
2. Настройка
3. Сеть и защита
4. Обслуживание
5. Краткая справка
6. Проверка и подтверждение
0. Выход
```

Настройки TrustTunnel находятся в разделе **2 → 6**.

## Результат внешнего сканирования

Результат контрольного запуска ByeByeVPN: **100/100, CLEAN; эмуляция ТСПУ — PASS / ALLOW; сильных и слабых сигналов — 0**. Сам инструмент одновременно предупредил, что результат TCP-сканирования может быть искажён промежуточным сетевым ПО. Это наблюдение одного запуска, а не доказательство невидимости VPN. Полная [сводка и вывод](docs/BYEBYEVPN_RU.md).

## Проверка после настройки

```bash
lucx-post-configure --validate
lucx-post-configure --repair-check
```

Затем откройте настроенные сайты в браузере и подключитесь каждым своим VPN-профилем. Для автотеста `--protocol-test` отдельно описаны [ограничения интерпретации](docs/TESTING_RU.md): отправка UDP-пакета сама по себе не подтверждает рабочий VPN.
